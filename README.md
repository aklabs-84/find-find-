# Run and deploy your AI Studio app

This contains everything you need to run your app locally.

View your app in AI Studio: https://ai.studio/apps/748ed19f-a091-4553-9ca7-8362b4559674

## Run Locally

**Prerequisites:**  Node.js


1. Install dependencies:
   `npm install`
2. Run the app (API 키 불필요 — MediaPipe 모델이 `public/models`에 들어 있어요):
   `npm run dev`
